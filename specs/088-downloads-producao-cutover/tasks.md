# Tasks — 088

**Ordem entre fases é rígida.** Cada fase é pré-requisito da seguinte, e inverter duas produz falha silenciosa — não erro visível. Especificamente: aplicar migrations antes de atualizar o clone aplicaria só 20 dos 29 arquivos sem acusar nada; subir o banco antes de fixar o `.env` congela a senha errada no volume (E009). Não pular, não paralelizar.

**Todo o código (Fases 0–2) vem antes do cutover (Fases 4–6).** O cutover transforma o acervo de beta em conteúdo público. Publicar primeiro significaria expor um catálogo com 80% de cards em placeholder cinza, 100% dos materiais sem sistema e autoria falsa nos materiais sem crédito — na primeira indexação do domínio. Corrigir depois é caro de um jeito que corrigir antes não é.

**Aprovação é por ação.** Cada comando de escrita na VM, cada deploy, cada commit e cada push exigem autorização nominal própria do mantenedor, mesmo dentro de uma fase já iniciada. Autorizar o `.env` não autoriza subir o banco.
